## Architectural Principles
1. **Always 3D**: Powered by Three.js with realistic perspective, soft lighting, and gentle orbit navigation.
2. **Beginner-First Clarity**: Synchronized comment-free code tracing, one-sentence plain English captions, and interactive playback (Step, Play/Pause, Speed, Reset).
3. **Pure Simulation**: Logic executed beforehand via a pure `simulate()` model returning step frames to guarantee rock-solid reproducibility.
4. **Rich Presets**: Pre-configured standard and edge cases for immediate exploration.
5. **Robust Token-Based Syntax Highlighting**: Clean single-pass tokenizer avoiding any nested regex replacement entity corruption.
