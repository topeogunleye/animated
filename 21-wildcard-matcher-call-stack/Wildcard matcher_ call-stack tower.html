How to read this call-stack tower

Each slab represents one active invocation of is_match(text, pattern), stacked on the call that spawned it. The top slab is the currently executing frame.
ACTIVE: running now.
WAITING: paused awaiting the return value of a child call above.
True: this call found a match (glows green).
False: this choice failed (the slab is popped/backtracked next).
Drag sideways to turn the 3D tower; double-click to reset angle.
