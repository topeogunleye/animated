Coins, bottom-up, in 3D

Goal: count combinations or find fewest coins using bottom-up dynamic programming.

drag to rotate · double-click to reset

Milestone 1/3 Ready to start guided audio tour.
How to read this

Each flat tile represents one amount, numbered below it. The number on the tile is the computed dynamic programming table value. A gold tile with NOW is the cell currently being computed. A blue tile with FROM is the sub-problem it builds on, joined by a white arc. Green tiles are completed (reachable amounts). Grey tiles are still 0 or ∞ (not reached yet). Drag sideways to rotate the 3D perspective; double-click to reset view.
