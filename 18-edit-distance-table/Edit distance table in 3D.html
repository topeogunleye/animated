Edit distance: filling the table, in 3D

Goal: count the fewest single-letter edits (insert, delete, replace) that turn string a into string b.

drag to rotate · double-click to reset

Milestone 1/2 Ready to start guided audio tour.
How to read this
  • Each tile is dp[i][j]: fewest edits to turn the first i letters of a (rows) into the first j letters of b (columns). \u2205 means no letters.
  • Grey tile: empty. Blue tile: filled in. Raised yellow tile: being filled now (its two letters turn orange). Teal tile: a tile it reads from. Purple tiles: the winning route back, at the end.
  • Arrow pointing down (orange) = delete a letter of a. Arrow pointing right (blue) = insert a letter of b. Diagonal arrow (green) = replace, or free match when letters are equal. Thick arrow is the winner.
