How to read this visualization

Each bar is a number; height is proportional to magnitude. Values are above bars and indices (0, 1, 2…) are in front.
Blue bar & arrow i: the first number of the pair.
Orange bar & arrow j: the second number of the pair. When j sits past the last bar, it has run off the end.
Green bars & beam: the matching pair that adds up to the target.
Drag the 3D scene sideways to rotate; double-click to reset angle.
